# Design review renders

Generated by `tools/review.py` (`python3 review.py [name ...]`) from the board,
the footprint libraries and the enclosure STLs. Each image shows one thing to
check against the manufacturer's drawing; the checklist and the reasoning are in
`../design-notes.md` §7.

| files | what they show |
|---|---|
| `polarity_overview.png`, `polarity_1.png` … `polarity_4.png`, `polarity.json` | pin 1 / cathode / + of all 40 polarised parts (red rings) and the JLC CPL rotation of each, for comparison with JLCPCB's placement preview |
| `fp_relay_K1.png` | K1 G6K-2F-Y pads and nets (normally-closed contacts 2 and 7 to GND) |
| `fp_smd_1.png` … `fp_smd_4.png` | SOT-23 MOSFETs, SOT-23 diodes and REF3030, SOT-23-5/6 ICs, DPAKs: pad numbers and nets |
| `fp_led_D3.png` | side-view LED footprint: lens direction and cathode pad |
| `fp_bnc_J2.png`, `fp_toggle_SW1.png`, `fp_pot_RV1.png`, `fp_dcjack_J1.png`, `fp_jack35_J6.png`, `fp_dsub_J5.png` | panel-part footprints with hole sizes and nets |
| `toggle_function.png`, `pot_direction.png` | which way the ENABLE lever and the knobs work |
| `layout_current_path.png`, `layout_kelvin.png`, `layout_ttl_input.png` | copper close-ups with the important nets highlighted |
| `sec_front_*.png`, `sec_rear_*.png` | cross-sections through every panel hole: printed panels, base, lid, PCB and the parts at datasheet dimensions |
| `panel_front.png`, `panel_rear.png` | the panels seen from outside, with the parts behind them outlined |
| `lid_clearance.png` | heights of all parts against the lid |
| `cable_de9.png`, `j5_face.png` | wiring of the DE-9 diode cable |
| `schematic.png`, `board_3d_*.png` | schematic sheet and 3D views |
